## Activer GitHub Pages

1. Sur GitHub, ouvrir **Settings → Pages**.
2. Dans **Build and deployment**, choisir **Source : Deploy from a branch**.
3. Sélectionner la branche `main` et le dossier `/ (root)`, puis **Save**.
4. Les URL ci-dessus sont actives au bout d'une à deux minutes.

## Fichiers

- `index.html` : page d'accueil avec liens vers les deux pages.
- `assistant.html` : présentation de l'assistant, aide et contact.
- `confidentialite.html` : politique de confidentialité (RGPD).
- `privacy.html` : redirection vers `confidentialite.html`.
- `assets/style.css` : feuille de style commune.
- `.nojekyll` : désactive le traitement Jekyll de GitHub Pages.
